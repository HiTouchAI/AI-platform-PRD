# HiTouch AI 中台产品需求文档

AI 中台面向 HiTouch 内部，提供 AI 辅助应用制作、发布、发现与使用的统一平台能力。

## 模块

| 模块 | 状态 | 说明 |
| --- | --- | --- |
| [应用中心](./app-center/) | 一期 | HTML 小工具的发布、发现、使用与版本管理 |
| Skill 中心 | 规划中 | Skill 管理与分发（独立需求，不在应用中心一期范围） |

## 一期范围

应用中心一期（详见 [`app-center/应用中心一期需求文档.md`](./app-center/应用中心一期需求文档.md)）覆盖：

- 从 Hermes Session 发布 HTML 应用到应用中心
- 应用中心内新建应用（AI 辅助制作）
- 应用列表、搜索、详情、在线使用、点赞
- "我发布的"应用管理
- 版本记录与更新
- 运营后台管理
- 使用数据统计（使用人数、使用次数、点赞人数）

## 协作方式

- PRD 文档为事实源，以本文档为准
- 需求变更通过 PR 提交，需产品负责人 review
- 技术方案由研发在满足验收标准的前提下自主决定
