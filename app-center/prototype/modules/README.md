# 应用中心一期模块化原型

当前目录将一期单页 Demo 拆为技术实现可按需读取的页面：

- `index.html`：HiTouch 工作台入口；
- `session.html`：Hermes Session 与 HTML 地址；
- `renderer.html`：HTML 预览与发布入口；
- `publish.html`：发布信息填写与确认；
- `app-center.html`：应用列表、搜索、点赞与使用；
- `app-detail.html`：完整说明、三项统计、点赞与使用；
- `assets/`：共享样式、状态和页面工具。

目录外的 `../应用中心一期Demo.html` 是当前连续演示基线。模块化页面必须保持与其一期范围一致：不包含新建应用、修改、版本或“我发布的”。

旧版模块化原型已备份为 `../应用中心一期原型.legacy-20260727/`，可在迁移期间用于对照，不作为交付入口。
