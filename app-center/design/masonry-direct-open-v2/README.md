本目录用于确认应用中心发现页的视觉优化方向，不代表修改既有发布、权限或快照运行契约。

## 本轮范围

- 保留瀑布流布局。
- 暂时保留现有 HTML 首屏缩略图及其生成链路。
- 强化应用名称，将作者、部门、用途和统计降为次级信息。
- 悬浮时仅突出当前卡片，提供“立即使用”和收藏入口。
- 点击缩略图、名称或“立即使用”均直接打开应用，不经过快速预览或公开详情页。
- 保持登录、ACL、上架状态、缩略图鉴权、不可变快照运行和统计口径不变。

## 不在本轮

- 快速预览或详情抽屉。
- AI 生成封面、用户上传封面。
- AI 自动分类或发布链路改造。
- “我的收藏”完整能力；该能力并入二期，本轮只预留卡片入口。
